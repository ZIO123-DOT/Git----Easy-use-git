Git 控制台 · 便携版 v1.0.0
================================

【怎么用】
1. 把整个压缩包解压到任意文件夹（不需要安装、不需要管理员权限）
2. 双击「Git 控制台.exe」运行
3. 首次使用：选择平台 → 点「打开 Token 生成页」按引导生成 Token → 粘贴 → 进入控制台

【支持平台】
- GitHub（推荐 Classic Token，勾选 repo + delete_repo 权限）
- GitLab / Gitee / GitCode（Personal Access Token，勾选 api / read_user 权限）

【安全说明】
- Token 只保存在你自己的电脑上（Windows 凭据加密存储），不经过任何第三方服务器
- 所有请求直接从本机发往平台官方 API
- 想删除所有数据：直接删掉解压出来的文件夹即可，程序不写注册表、不装服务

【常见问题】
- 登录失败 / 一直转圈：先点登录页的「网络设置 / 自动探测代理」试试（公司网络或校园网可能需要代理）
- Token 无效：检查权限是否勾全、Token 是否复制完整（生成后只显示一次）
- 换电脑迁移：把整个文件夹拷走即可，但**账号列表与 Token 都不会跟着迁移**（账号与 Token 是同一份 Windows 凭据加密数据，绑定本机与本用户），换机后需重新添加各平台账号并登录：账号与 Token 数据不随文件夹走

【提醒】
- 请勿勾选 delete_repo 权限给不信任的 Token；删除仓库按钮有二次确认，但仍请小心操作
- 建议每个平台只授予必需权限
